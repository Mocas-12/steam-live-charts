# 数据口径与验证

## 数据时间

- API `meta.updated_at` 是这份数据开始采集的 Unix 时间，缓存命中和失败回退不会改写它。
- `served_at` 是本次响应时间；`age_seconds` 是数据年龄；`ttl` 是该榜单缓存期限。
- `source` 为 `live`（当前进程采集）或 `disk`（磁盘快照）。`live` 不保证数据仍新鲜，必须同时检查 `stale`。
- `refresh_failed` 表示上次刷新失败；`stale` 表示超出期限、刷新失败或使用磁盘快照。页面统一展示 UTC+8，保留日期，避免跨日误读。
- 一轮最热榜包含多次并发请求，采集不是原子快照。采用开始时间保守标注数据年龄；官方峰值来自另一接口，不能当作当前在线数的同步上限。
- 每日种子保留原始采集时间。旧种子缺少上周排名时不推算周变化；磁盘快照不恢复异动和趋势，避免把旧信号当成当前信号。

## 榜单与人数

- 最热榜的候选集合来自 Steam 官方榜单，在该集合中按已取得的当前在线人数排序，并非扫描整个 Steam 商店。
- “榜单 Top N 在线合计”仅求和这些游戏的有效人数，不代表整个 Steam 平台在线人数。显示覆盖款数，未知人数不计为零；真实零人数仍计入覆盖数。
- 未取得人数的条目置后，人数和周变化显示 `—`。所有人数均失败时，本轮构建失败，保留旧榜单。
- 周排名变化 = 上周官方排名 − 当前实时排名。新上榜仅在接口明确返回 `last_week_rank == -1` 时显示；字段缺失表示未知。
- 搜索类榜单先过滤再重新编号，避免出现跳号。

## 异动与趋势

- 异动比较最近 30 分钟与此前 2 小时的平均在线人数，均值按采样持续时间加权。
- 基线人数须至少为 200，涨幅须至少为 30%。采样窗口覆盖不足、任意相邻采样间隔超过 5 分钟，或最近采样超过 5 分钟时不发布信号。
- 历史查询与曲线只返回最近 24 小时的采样；进程重启后重新积累。不会把“没有异动”解释成“采样不足”。
- 原生前端在数据超期时即使没有收到新响应，也会隐藏旧异动与趋势。Streamlit 每 60 秒重新判断状态。
- 免费榜请求失败表示“状态未知”，不等同于“当前没有活动”。

## 验证

安装 `requirements.txt` 和 `pytest`，在仓库根目录运行：

```bash
python -m pytest tests/ -q
node --check static/app.js
node --test tests/test_frontend.cjs
```

测试使用离线源，覆盖缓存时间、并发取消、失败回退、部分人数、磁盘种子、时间窗口、折扣元素附加属性、七个 HTTP 榜单以及 Streamlit 重跑。真实 Steam 可用性仍受限流、网络与上游页面结构影响。
