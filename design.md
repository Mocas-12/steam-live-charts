# Gamecharts interface system

Hallmark v2.0.0, app scope. Preserve Gamecharts, dark graphite, gold selection, green deals and red decreases. The signature is real game covers beside aligned live counts.

One capped 1240px container. 16px body; 32px desktop and 26px phone page titles. Tables use 92px rows, 120px covers and tabular numerals. On phones covers become 84px and primary values sit under titles. Tabs use a gold underline, never glowing pills. Input surfaces are solid with an 8px radius. Mono is reserved for numerical measurements.

FastAPI and Streamlit share hierarchy and spacing, with each retaining its own existing features. Keep all seven boards, filters, refresh behavior, trust metadata, error/empty/loading states and original input/handler IDs. CSS is separate from Python rendering. No backend, API or watchlist contract changes.

Every actionable control has an immediate focus ring; reduced-motion disables animation. Existing artwork, prices and source attributions remain untouched. Branch baseline is recorded in the delivery manifest; revert this design commit to restore.
